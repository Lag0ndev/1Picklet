# 1Picklet

**The Picklet Hub** — a central place for everything Picklet.

## Getting Started

### Prerequisites

- Node.js 18+ 
- npm (or yarn / pnpm)

### Install & Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the hub.

### Build for Production

```bash
npm run build
npm start
```

## Deploy on Vercel

This project is ready for Vercel. Just connect the repo and deploy — `vercel.json` is already configured.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/Lag0ndev/1Picklet)
